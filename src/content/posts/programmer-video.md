成品是一条 10 分 37 秒的《程序员简史》：140 个镜头、复古美漫画风，配有配音、字幕、音效和背景音乐。
分工如下：

- **Claude Code**：写稿、写脚本、剪辑；
- **Codex**：画图、审片；
- **我**：给需求、做取舍。

整个过程我没有手写代码。下面是核心流程、用到的工具，以及每一步我实际发出的提示词。

---

## 工具清单

| 工具 | 干什么 | 备注 |
|---|---|---|
| **Claude Code** | 总控：拆参考片、写分镜、写所有脚本、调用其他工具 | 终端里对话完成 |
| **Codex CLI** | ① 生图；② 当评审给成片打分 | 用 ChatGPT 账号，生图有额度限制 |
| **codex-draw** | 我自己写的 Claude Code 技能：用 Codex 内置生图，传提示词和参考图，输出 PNG | 核心是一条 `codex exec` 命令 |
| **ffmpeg-skill** | Claude Code 的视频处理技能：推镜、叠加、拼接、混音、字幕、响度、平台规格检查、抽帧 | 让 AI 不手写 ffmpeg，每步都有校验 |
| **edge-tts** | 中文配音 | `zh-CN-YunxiNeural`，语速 +12% |
| **rembg** | 人物、道具抠图 | 模型 `isnet-general-use` |
| **Python + PIL** | 把背景、人物、标题、贴纸合成成每个镜头的画面 | Claude 写的脚本 |
| 素材 | Wikimedia 历史照片（作参考或直接用原件）、Kenney 音效（CC0）、Kevin MacLeod 音乐（CC BY 4.0） | |

## 核心流程

```
参考片 ──拆解──▶ 分镜表 shots.json ──┬─▶ 配音 edge-tts ──▶ 镜头时长
                                    ├─▶ 出图清单 ──codex-draw──▶ 插画 ──rembg──▶ 抠图
                                    └─▶ PIL 合成每个镜头画面
                                              │
              推镜 + 叠加 + 拼接 + 字幕 + 音效 + 音乐 + 响度（ffmpeg-skill）
                                              │
                                     成片 ──Codex 评审──▶ 修改 ──▶ 发布
```

**关键设计：一切从一张分镜表生成。** 每个镜头一行 JSON，改文案、换图、调布局都只改这里，然后一条命令重新渲染：

```json
{"id": "s010", "text": "1804年，你是法国里昂的一名织布工人。",
 "bg": "lyon_street", "chars": ["hero_1804"], "title": ["LYON", "1804 · 里昂"]}
```

## 第 1 步：找一条参考片，让 AI 拆解它

这一步最重要。与其空口描述风格，不如直接给一条样片。

> **我的提示词**
> `/ffmpeg-skill 你分析一下这个视频 file:///…/bilibili_BV1NNge6PEHP.mp4 我想做一个关于 "程序员" 这个职业的视频，讲述它的发展历史，用一些关键人物和关键事件把它串起来，讲述的风格，人物的画风想参考上面的视频，人物可以从网上下载，然后用 /codex-draw 来画成视频中的那种风格，其他的需要的画面也是一样`

Claude 会做这几件事：

- 抽帧拆出参考片的叙事套路：第二人称“假如你是……”，“不过问题出现了”的转折；
- 拆出画面语法：网点漫画、固定舞台、大字标题在人物身后、贴纸；
- 截几张干净的帧当风格参考图；
- 给出一份方案（时长、配音、主角设定），让我确认。

## 第 2 步：先出样张，定稿后再批量

先画三张样张：主角、一位历史人物肖像、舞台背景。不满意就重画。**定稿的样张会作为之后每张图的参考图**，保证全片画风统一、主角始终是同一张脸。

> **我的提示词**
> `1. 样张可以当定稿，背景选择 sample_stage_v2.png 2. 帮我安装 rembg 3. 试听的文件你帮我打开一下`

## 第 3 步：批量出图

Claude 会生成一份出图清单，每张图写明类型、参考图和提示词，再自动拼上“类型要求”和“全局风格”两段固定文字。

**全局风格**（每张图都带）：

```
风格严格参考附带的风格参考图：复古美式漫画/波普艺术风格，粗黑墨线勾边，本戴点(Ben-Day dots)网点阴影，
平涂色块，略带做旧纸张颗粒质感，色彩饱和但偏复古。不要复制参考图里的任何文字、水印、logo。
画面中无任何文字、无水印。16:9横版。
```

**类型要求**（以人物立绘为例，纯色底方便抠图）：

```
全身人物立绘：人物从头到脚完整入画，居中，占画面高度约85%，背景为纯米白色纸张底色，
没有地面、没有阴影、没有任何其他背景元素（方便抠图）。
```

**单张提示词**（真实人物附上历史照片作参考）：

```
1972年约31岁的丹尼斯·里奇全身站姿。脸型参考 kt_dmr_1973.jpg 右边那位：不戴眼镜；深棕色微卷的头发；
修剪整齐的短络腮胡；温和的笑容。注意：他和肯·汤普森（大框眼镜、长发、浓密大胡子）必须一眼能区分。
画法与 sample_hero.png 一致。
```

**codex-draw 的核心**就是一条命令：

```bash
codex exec --skip-git-repo-check -s read-only -i 参考图1.png -i 参考图2.png \
  -- "调用内置图像生成工具生成一张图，不要做其他任何事情。以附带的图片作为参考图进行编辑。画面要求：…"
```

**额度用完怎么办**：Codex 生图有额度，一个窗口只能画十几到几十张。让 Claude 写一个续跑脚本：从报错里解析“try again at 4:10 AM”，到点自动接着画，画完自动抠图。晚上挂着，早上图就齐了。

> **我的提示词**
> `可以，开始批量出图吧`
> `先做试片，同时挂定时任务 2:15 续跑`
> `画完了自动渲染完整版`

## 第 4 步：配音和字幕

- **配音**：edge-tts 每个镜头生成一段音频，**镜头时长就等于配音时长**，画面自然和声音对齐。
- **多音字**：在分镜里加一个 `tts` 字段，用同音字替换（“十万行”写成“十万航”），字幕仍显示原文。
- **字幕**：自动工具在逗号处切得很乱，于是让 Claude 自己写切分：每条 11～16 字，去掉句尾标点，时间按发声区间分配。

> **我的提示词**
> `1. 节奏偏慢了一点点，字幕的很多逗号位置不对 2. 要加背景音乐 3. 可以开始 5-12 章`
> `对了，里面的 行 字，应该读 hang， 而不是 xing， 你这个能改吗`
> `现在的速度偏快了一点点，可以适当调整慢一点点`

## 第 5 步：合成、音效、音乐、渲染

**画面**：每个镜头合成两层。

- **底层**：背景 + 人物 + 道具，做缓慢推镜；
- **上层**：标题、贴纸、卡片，延迟 0.25 秒淡入，模拟“弹出”。

几个让画面不像“AI 糊出来”的做法：

- **英文大字放在人物身后**，中文标题自动找没有人物的空位，不挡脸；
- **需要可读文字的地方不让 AI 画**：聊天框、代码、终端、名言卡、名单卡，都用程序排版；
- **史料用原件**：手稿、日志直接用公有领域的照片，并注明出处；
- **原理用图解**：织机“有孔提线、没孔不动”，用代码画一张对照图。

**音效**：我只说了一句“细节不够”。Claude 分析了参考片的立体声，发现音效集中在四种时刻：人物登场、换背景、贴纸出现、关键词出现。于是写了规则，自动在全片铺了约 220 个音效，并按画面位置分左右声道。

> **我的提示词**
> `我看完了，还有一点细节问题，我给你参考的视频里面还有很多细节的声音，比如一个新的概念出现时等等，现在的视频整体性可以，细节不够，你看看`
> `另外我想在视频的角落打上水印 """@井久"""`

**交付标准**：响度 -14 LUFS、真峰值 ≤ -1 dBTP，用 ffmpeg-skill 的 `check --platform youtube` 过 12 项规格检查。

## 第 6 步：让 Codex 来审 Claude 的片子

这一步的提升最大。自己反复看，很快就看不出问题了；换一个厂商的模型当评审，能挑出大量自己发现不了的问题。

> **我的提示词**
> `~/workspace/mg-styles-15 这个项目里有一个使用 codex 交叉验证视频质量的工具，你看一下`
> `好，改好提示词跑一轮评审`

Claude 会准备好评审材料，交给 Codex：

- 分镜和时间码；
- 每个镜头的抽帧拼图；
- 参考片截图；
- 字幕文件；
- 音效事件列表；
- 规格检查结果。

**评审提示词的骨架**（节选）：

```
You are a senior jury member for Chinese popular-science explainer videos (a top B站 知识区 channel lead,
a documentary story editor, and a history-of-computing fact checker). You did NOT make this film.
Judge it harshly and precisely. Kindness is useless here; specificity is everything.

1. Look at all contact sheets and at least 10 full-resolution frames: faces, hands, garbled AI lettering,
   cut-out halos, subtitle collisions, consistency of the protagonist.
2. Fact-check the narration line by line. Separate "wrong", "disputed / oversimplified" and "fine".
3. Check the writing: hook in the first 10 s, chapter transitions, whether the ending lands.
4. Score 1–10 on 8 dimensions (5 = competent amateur, 8 = top B站 知识区 channel). Do not inflate.
5. Give 8–15 fixes ordered by impact on a viewer's impression, each with shot id, timecode and a concrete how-to.
   At least two fixes must raise engagement, not just polish.
Return in Chinese.
```

运行方式：

```bash
codex exec --skip-git-repo-check -s workspace-write -C 评审目录 -o 评审目录/last_message.md - < PROMPT.md
```

Codex 第一轮挑出的问题：

- 织机原理说反了；
- Unix 和 C 的年份混在一起；
- 画面里有 AI 写的假字；
- 标题挡脸；
- 结尾空洞。

第二轮又挑出：

- 汤普森的妻子是去看望**他的**父母，不是“回娘家”；
- 第一个网站是 1990 年上线，不是 1991 年；
- “码农”镜头是五个同脸人，“一眼 AI 批量图”。

史实分从 4 涨到 5，故事分从 5 涨到 6。

## 第 7 步：修改与取舍

评审意见不全盘接受，**最后拍板的是人**。

> **我的提示词**
> `把必须改和建议改的都改掉`
> `新的结尾不符合现在的情况，最后的结尾，应该是2026年， claude code 和 codex 这类 ai agent 出现， 彻底改变了程序员行业，以前是 talk is cheap, show me the code ，现在是 code is cheap, show me the talk`
> `他们的名字不用读出来， 展示出来就可以了`
> `1，2，3 类都做，重画图没问题，"几处说得太满的句子" 这个不用改`

我的做法是让 Claude 先把评审意见按改动代价分成三类：

1. 改文案；
2. 改排版；
3. 重画。

我再逐类决定做不做。Codex 两次建议把结尾改成别的样子，我都没采纳。

## 第 8 步：发布

> **我的提示词**
> `我要把这个视频发布到小红书，抖音，视频号和B站，你帮我取一个标题`
> `再帮我写一下各平台的简介和标签`
> `帮我选一帧做封面，导出图片`

Claude 按各平台的字数限制和调性分别写了标题、简介和标签，还附上 B站章节时间戳。封面用片中五个时代的主角重新排版，出了 16:9、4:3、3:4 三个尺寸。

## 给想照着做的人：五条经验

1. **先找参考片**，让 AI 拆出叙事套路、画面语法和声音规律，比描述风格靠谱得多。
2. **样张定稿再批量**。定稿样张就是之后所有出图的参考图，这是画风统一的关键。
3. **一切从分镜表生成**。改一处，全片一条命令重跑，绝不手工拼接。
4. **“真”的东西别让 AI 画**：文字用排版，史料用原件，原理用图解。
5. **用另一个模型审片**，把它当成挑剔的编辑，但取舍由你来做。

这条视频的结尾说“Code is cheap. Show me the talk.”，它本身就是这么做出来的：我没写代码，只是把想要的东西说清楚了。
