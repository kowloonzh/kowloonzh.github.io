> 一条 10 分 37 秒的中文科普视频。从“打孔卡织布机”讲到 2026 年的 AI 智能体，140 个镜头、90 多张插画、全程配音、字幕、音效和背景音乐。
> 除了最后的审美判断，几乎每一步都是在终端里跟 AI 对话完成的：**Claude Code 当导演兼剪辑，Codex 负责画画和挑刺。**

## 一、起点：先找一条“想抄”的参考片

我手里有一条很喜欢的 B 站科普视频（`BV1NNge6PEHP`）。它的风格很鲜明：

- **第二人称叙事**：“假如你是一名……”，把观众直接放进历史现场；
- **复古美漫画风**：粗黑描边、本戴点网点、做旧纸张质感；
- **固定的“舞台”**：米白天空 + 透视地砖，人物站上去讲故事；
- **大字标题**：英文大字在人物身后、中文标题在前；
- **贴纸和音效**：问号、感叹号、汗滴，每一次新概念出现都有“嗖”“咚”。

我给 Claude Code 的需求只有一句：**做一条讲“程序员这个职业从哪儿来”的视频，用关键人物和事件串起来，旁白风格和画风照着参考片来。**

Claude 先把参考片拆了一遍：截取干净的街景、肖像、舞台帧作为风格参考图（`refs/style/`），总结出叙事套路和镜头语法，然后和我确认了几个默认项：

| 决定 | 选择 |
|---|---|
| 时长 | 约 10 分钟，分批交付 |
| 配音 | edge-tts，`zh-CN-YunxiNeural` |
| 主角“你” | 一位戴眼镜、穿卫衣的亚洲程序员，每个时代换装但同一张脸 |
| 真实人物 | 从网上找真实照片当参考，再重绘成参考片的画风 |
| 流程 | 先做样张，定稿后再批量 |

## 二、整体流水线

整个项目就是一个文件夹 + 一组 Python 脚本，所有东西都可以重跑：

```
script/shots_all.json        分镜表（唯一的“剧本源”）
        │
        ├─ tts.py            → audio/<镜头>.mp3 + .vtt        配音（每镜头一段）
        ├─ assets_*.json     → draw_batch.py → art/*.png       出图（Codex 生图）
        │                    → cutout.py     → art/cut/*.png   抠图（rembg）
        ├─ compose.py        → build/frames/<镜头>_base/over.png   合成静帧
        ├─ subs.py           → 字幕 ASS/SRT + 水印
        ├─ sfx.py            → 音效轨（立体声）
        ├─ music_bed.py      → 背景音乐轨（按镜头起伏）
        └─ build_video.py    → 推镜、叠加、拼接、混音、烧字幕、响度 → build/full_vN.mp4
```

视频处理全部通过一个 ffmpeg 技能包里的脚本完成（`insert` 推镜、`overlay` 叠加、`join` 拼接、`audio` 混音、`caption` 字幕、`loudness` 响度、`check` 平台规格检查、`look` 抽帧看图），**不手写一行 ffmpeg 命令**。这样每一步都有校验，出了问题也能说清楚是哪一步。

### 分镜表：一切的源头

每个镜头就是一条 JSON：

```json
{"id": "s010", "ch": 0,
 "text": "1804年，你是法国里昂的一名织布工人。",
 "visual": "棕褐色里昂街景，主角穿19世纪初工人装",
 "bg": "lyon_street", "chars": ["hero_1804"],
 "title": ["LYON", "1804 · 里昂"]}
```

旁白、画面描述、背景、出场人物、标题、贴纸都在这里。改文案 = 改这一行，然后重跑。最终版一共 **140 个镜头，13 个章节**（冷开场 + 序章 + 12 章）。

## 三、画面：让 Codex 当插画师

### 1. 样张先行

正式出图之前先画了三张样张：主角、阿达·洛夫莱斯的肖像、舞台背景。舞台第一版是棋盘格地面，我不满意，第二版换成参考片那种浅薄荷绿地砖，定稿。**这三张样张后来成了所有出图的“风格锚点”**，每张图都把它们当参考图一起喂进去。

### 2. 用 Codex 画图

Claude 本身不能生成图片，所以我写了一个小工具 `codex-draw`：用 Codex CLI 调用内置的生图功能，传入提示词和参考图，输出 PNG。

出图清单 `assets_*.json` 里每张图一条，分成五类，每类自动拼接不同的构图要求：

- `char` 全身人物立绘，纯米白底（方便抠图）
- `prop` 道具
- `portrait` 半身肖像，构图对齐阿达样张
- `scene` 完整场景
- `sepia` 棕褐色做旧的历史场景，中间留空给主角站

再加一段全局风格描述（复古美漫、粗墨线、网点、**画面中不要任何文字**）。真实人物都附上从 Wikimedia 下载的历史照片作参考，比如：

> 1969 年的肯·汤普森（约 26 岁），外貌参考 thompson_ritchie.jpg 中坐着的那位……画法与 sample_hero.png 一致。

### 3. 额度用完了怎么办

Codex 的生图有额度限制，一个窗口大概只能画十几到几十张。于是又加了两个脚本：

- `draw_batch.py`：多线程批量出图，已存在的跳过；一旦日志里出现 “usage limit”，立刻停止发新请求；
- `draw_until_done.py`：从报错里解析 “try again at 4:10 AM”，**自动等到额度恢复再接着画**，画完自动抠图。

所以晚上挂上任务去睡觉，第二天早上图就齐了。最终一共画了 **90 多张**。

### 4. 抠图与合成

- `rembg` 把人物、道具抠成透明 PNG，贴纸表按网格拆成 12 个单独贴纸；
- `compose.py` 用 PIL 把每个镜头合成两层：
  - **base 层**：背景 + 人物 + 道具（之后做缓慢推镜）
  - **over 层**：大字标题 + 贴纸 + 卡片（延迟 0.25 秒淡入，模拟“弹出”）

几个踩过的坑和解法：

- **标题挡脸**：英文大字画在人物*身后*（先画标题，再盖上抠好的人物）；中文标题用人物的 alpha 蒙版找一段没人的空位，放不下就缩小字号再找。
- **AI 画的“伪文字”**：生图模型写字总是鬼画符。凡是需要可读文字的地方——聊天窗口、HTML 代码、终端日志、名言卡、名单卡——全部改成 **PIL 排版的卡片**，真实字体、真实内容。
- **真实史料用真件**：阿达的《注释 G》、哈佛 Mark II 那页贴着飞蛾的工作日志，都直接用公有领域的原件照片合成，并在角落注明出处，不让 AI 去“画”一份假的历史档案。
- **原理讲不清就画图解**：雅卡尔织机“有孔提线、没孔不动”的机制，用代码画了一张左右对照的原理图。

## 四、声音：配音、字幕、音效、音乐

### 配音

`edge-tts` 每个镜头生成一段 mp3，**镜头时长 = 配音时长**（需要停顿的镜头加一个 `hold` 字段多停几秒）。语速前后调了好几次：+8% 偏慢 → +15% 偏快 → 最终 +12%。

多音字是个小麻烦：“十万行代码”被读成 xíng。解决办法是在分镜里加一个 `tts` 字段，用同音字替换（“十万**航**代码”），字幕仍显示原文。

### 字幕

自动字幕工具会在逗号处把句子切得很怪（下一条以“，”开头）。于是自己写了 `subs.py`：

- 按标点切短句，用动态规划把碎句合并成每条 11～16 字；
- 句尾标点去掉，句中逗号显示成空格；
- 时间按字数分配在 edge-tts 给出的实际发声区间里；
- 同时输出烧录用的 ASS 和可开关的 SRT 软字幕；
- 右上角的半透明水印 “@井久” 也作为 ASS 的一层，随字幕一起烧进去，不多一次转码。

### 音效

看完第二版我觉得“整体可以，细节不够”——参考片里每出现一个新概念都有声音。Claude 分析了参考片的立体声侧声道，发现音效集中在四种时刻：**人物登场、换背景、贴纸出现、关键词标题出现**。`sfx.py` 就按这些规则自动铺音效：

- 换章节 → 大“嗖”；换背景 → 轻“嗖”；标题 → “嗖 + 咚”；人物登场 → “啵”；贴纸按类型配音；
- 个别镜头加场景音：织机木头声、打字声、登月警报、翻书声……
- 素材来自 Kenney 音效包（CC0），少量用 numpy 直接合成；
- 按画面里元素的左右位置做立体声声像；
- 间隔太近的音效只保留优先级最高的那个，避免“叮叮咚咚”糊成一片。

### 背景音乐

Kevin MacLeod 的 *Wallpaper*（CC BY 4.0）。`music_bed.py` 按分镜给音乐做起伏：冷开场不放音乐、正片开始淡入、登月警报和 ENIAC 名单那几秒压低音乐。最后统一做压缩、限幅和响度标准化到 **-14 LUFS**，过 YouTube 的 12 项规格检查。

## 五、最有意思的一环：让另一个 AI 来审片

做到第四版，我自己已经看不出明显问题了。于是借用了另一个项目里的“交叉验证”思路：**让 Codex（GPT 系列模型）当一个严苛的评审团**，给 Claude 做的片子挑刺。

给 Codex 的材料包括：分镜表、带时间码的字幕、每个镜头的抽帧拼图、参考片的截图、音效事件列表、技术检查结果。评审提示词要求它：

1. 逐句核对史实，给出处；
2. 按 8 个维度打分（史实、故事、配音字幕、风格还原、插画、视觉节奏、声音、技术），8 分 = B 站头部知识区水平；
3. 按“观众印象”排序给出修改清单。

它非常不客气。第一轮挑出的问题包括：

- 雅卡尔织机“有孔/没孔”的方向说反了；
- C 语言和 Unix 的年份混在一起；
- 阿达“第一个程序员”说得太绝对；
- 画面里大量 AI 生成的假文字；
- 字压在人脸上；
- 片尾金句“没有证据支撑”。

Claude 按清单逐条修改，出了 v5、v6。第二轮复审的分数变化：

| 维度 | v4 | v6 |
|---|---:|---:|
| 史实 | 4 | 5 |
| 故事 | 5 | 6 |
| 配音与字幕 | 6 | 6 |
| 风格还原 | 6 | 6 |
| 插画 | 6 | 6 |
| 视觉节奏 | 5 | 5 |
| 声音 | 5 | 5 |
| 技术 | 8 | 8 |

第二轮又揪出两个硬伤：汤普森的妻子带孩子是去看望*汤普森的*父母（不是“回娘家”），时间约一个月；第一个网站是 1990 年底上线、1991 年才对外公开。它还指出：

- 阿达站在 20 世纪的磁带机房里，时代错位；
- 飞蛾日志是 AI 伪造的手写；
- “码农”镜头是五个同脸主角戴草帽，“一眼 AI 批量图”；
- 汤普森和里奇画成了同一款大胡子，认不出谁是谁。

这些在 v7 里都改了：

- 换上日志原件；
- 照真实照片重画里奇（不戴眼镜、短胡子），和汤普森一眼区分；
- “码农”改成主角一个人扛着键盘当锄头；
- 2008 年那一章从“罗列三个网站名”改成一个小游戏的完整故事：上架应用商店 → 陌生人在 GitHub 提交修复 → 在 Stack Overflow 查到闪退原因 → 游戏又跑起来了。

**体会**：两个不同厂商的模型互相制衡，效果比我自己反复看好得多。但也不是全盘照收。比如 Codex 两次建议把结尾改成一个“需求没说清 → 返工”的演示，我觉得不符合我想表达的东西，就坚持了自己的版本；有几处它认为“说得太满”的修辞，我也选择保留。**AI 负责找问题，取舍还是人来做。**

## 六、结尾：Code is cheap, show me the talk

最初 Claude 写的结尾是一个“AI 写的网页漏洞百出”的小剧场。我否了：这不符合 2026 年的现实。现在的结尾是：

> 二十多年前，林纳斯说过一句名言：**Talk is cheap. Show me the code.**
> 2026 年，Claude Code、Codex 这样的 AI 智能体，你说一句需求，它自己读项目、改文件、跑测试、修 bug。
> 这句话被倒了过来：**Code is cheap. Show me the talk.**
> 代码越来越便宜。值钱的，是你能不能把想要的东西，想明白、说清楚。

这其实也是这条视频本身的制作方式：**我几乎没有写代码，我做的事情就是“说清楚”**：

- 要什么风格；
- 哪里节奏慢了；
- “行”该读 háng；
- 名字不用念出来、展示出来就行；
- 结尾该落在哪里。

## 八、如果你也想这么做

1. **先找一条参考片**，让 AI 把它的叙事套路、画面语法、声音规律拆清楚，比空想风格靠谱得多。
2. **样张先定稿**，再批量。样张就是之后所有出图的锚点。
3. **一切从一张分镜表生成**，改一处、全片重跑，不要手工拼。
4. **需要“真”的东西就别让 AI 画**：文字用排版，史料用原件，原理用图解。
5. **让另一个模型来审**，把它当一个挑剔的编辑；但最后拍板的是你。
